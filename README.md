# UNIX Practical 6 – CAT Command

## Aim

To create a file, display file content, concatenate multiple files, append file content, and number lines using the Linux `cat` command.

---

## Learning Objectives

After completing this practical, students will be able to:

1. Create a file using `cat`.
2. Display the contents of a file.
3. Concatenate multiple files.
4. Append file contents to another file.
5. Display line numbers using `cat -n`.
6. Submit Linux practical work through GitHub.
7. Understand automatic testing using GitHub Actions.

---
